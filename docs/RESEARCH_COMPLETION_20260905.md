# WeCover completion research

Checked: 2026-09-05. Primary official sources only. Read alongside the supplied PDF extraction (`artifacts/wecover-source-spec-20260905.txt`) and `FEATURE_ACCEPTANCE.md`. This research informs implementation; it is not legal approval, provider verification, or proof of local demand. User overrides: iOS and Android are primary; web supports them; English-Spanish replaces Korean-English; Stripe activation remains deferred.

## Priority implementation gates

| Area | Verified source / finding | Implementable requirement |
| --- | --- | --- |
| Project size | [NC G.S. 87-1](https://www.ncleg.gov/EnactedLegislation/Statutes/HTML/BySection/Chapter_87/GS_87-1.html) sets the general contractor threshold at $40,000 or more. [Current board guidance](https://www.nclbgc.org/laws-regulations/) agrees. | The PDF excludes these projects entirely. Block at intake, quote acceptance and approved change totals; evaluate the whole undertaking, not each payment or bundled line in isolation. Unknown totals are not evidence of eligibility. |
| Trade qualification | [NC plumbing/heating board FAQ](https://nclicensing.org/faq/) requires the appropriate qualification for covered work and says contracting must stop if the qualifying license holder leaves. Licenses renew annually. | Category-specific license, qualifying firm/person, current status and expiry must be independently reviewed before matching. Do not interpret a general contractor license as a plumbing/HVAC qualification. |
| License exceptions | [Board consumer guidance](https://nclicensing.org/consumer-awareness/) describes minor repair/service exceptions but also contains an obsolete $30,000 general-contractor threshold. | Use the current statute for dollar limits. Keep the PDF's conservative verified-license gate for plumbing/HVAC; do not let an LLM declare a legal exemption. A handyman-safe task list must exclude regulated system alterations. |
| Permits | [Mecklenburg permitting](https://code.mecknc.gov/permitting) identifies separate building/trade permits and exceptions to the low-cost residential exemption, including system design changes and HVAC replacement. [Trade permits](https://code.mecknc.gov/permitting/tip) can apply even without a building permit. | Under $40,000 does not mean permit-free. Store required/not-required/unknown, reviewer, reason, permit number, responsible contractor and inspection status. Unknown must require review before work starts; a customer skip cannot resolve it. |
| Workers compensation | [NC Industrial Commission employer guidance](https://www.ic.nc.gov/workers-compensation-claims/employers) generally requires coverage at three regularly employed workers; officers count, with exceptions and special cases. | Record coverage evidence or reviewed exemption reason and expiry. Do not automatically approve an exemption from a contractor's headcount checkbox. General liability and workers compensation are different evidence. |
| Verified badge | [NC board homeowner guidance](https://www.nclbgc.org/remodeling-home-improvement-contracts/) calls for license verification and proof of insurance. | Submission/self-attestation is pending review. Store official lookup/evidence reference, reviewer and reviewed-at time separately from provider-entered details; expiry or suspension removes matching eligibility. Insurance upload alone must not silently mark verified. |
| Price | PDF policy, not an externally proven statistic: fewer than 30 completed comparable local transactions means diagnostic fee only. | Count real completed comparable records, exclude fixtures and quotes, show sample count/source/update date. Do not repeat the PDF's public price ranges as a validated local average. No market sample was collected in this task. |
| Service area | PDF asks for a chosen initial 3-5 ZIP area but supplies no approved list. | Store an explicit operator-configured allowlist, with request address and provider overlap checks. Do not invent launch ZIPs or accept all Charlotte merely from a city label. Empty production configuration must show unavailable, not pretend coverage. |

The gate behavior above is product design derived from sources and the PDF. Exact permit exemptions, worker classification, service-agreement wording and background-check/FCRA procedures remain legal/operational review items; the app must not claim those are certified.

## Native payments and builds

- [Stripe React Native SDK](https://docs.stripe.com/sdks/react-native) recommends PaymentSheet. [Native payment acceptance](https://docs.stripe.com/payments/mobile/accept-payment?platform=react-native&type=payment) requires server integration as well as native UI. Keep secret keys and authoritative amounts on the server, bind each payment to approved scope, and reconcile payment status server-side. A successful client sheet is not permission to add charges. Disabled configuration must remain disabled throughout mobile booking and changes. Account signup, real credentials and live validation are still separate from code readiness.
- [Expo SDK reference](https://docs.expo.dev/versions/latest/) currently lists SDK 57 with React Native 0.86, React 19.2.3, minimum Node 22.13.x, Android 7+, iOS 16.4+, and Xcode 26.4+. Check the installed compatible patch versions; do not upgrade only one package arbitrarily.
- [SDK 57 official changelog](https://expo.dev/changelog/sdk-57) says the Hermes memory regression was fixed in `expo@57.0.9` / RN 0.86.2; development startup regression was fixed in `expo@57.0.17` / RN 0.86.3. These are leads for the previous emulator failure, not proof of its cause. Compare installed versions and measure a fresh run before claiming the issue resolved.
- [Local Expo compilation](https://docs.expo.dev/guides/local-app-overview/) uses Android Studio/SDK or Xcode. [Local EAS builds](https://docs.expo.dev/build-reference/local-builds/) do not officially support Windows, while native Android compilation is a different workflow. Do not equate a JavaScript export or mobile-width browser with an installed app.
- [EAS build setup](https://docs.expo.dev/build/setup/) distinguishes installable Android APK/iOS simulator builds from store builds, which need developer accounts and signing credentials. iOS local compilation requires a suitable Mac/Xcode environment. Cloud login, signing and paid services are not performed by this research.

## Completion evidence to collect

1. Installed Android and iOS: login, camera permission denial/recovery, real photo/video upload, Spanish original/translation, interrupted consultation recovery.
2. Server-backed lifecycle: verified provider eligibility, three-provider cap, immutable scope, itemized quote, booking/reschedule history, unapproved-change charge rejection, before/after evidence, receipt, review/dispute.
3. Dedicated provider timeout fallback, same-address safe bundles, completed-work maintenance/warranty records, multi-location approval access and annual report data.
4. Test empty ZIP configuration, expired/unverified provider, project reaching $40,000 through a change, permit unknown, fewer than 30 completed price samples, and payments disabled.

No recruitment, outreach, publication, purchase, legal determination, or real local market measurement was performed. PDF response-rate, pricing and growth targets remain hypotheses until measured against real transactions.
