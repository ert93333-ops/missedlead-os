## 브라우저 검사 재실행

일반 Vite 개발 서버가 멈추는 환경에서는 별도 테스트 빌드를 사용한다. 아래 데모 인증 플래그는 이 테스트 빌드에만 설정하며 제품 빌드에는 설정하지 않는다. API 응답을 고정한 검사이므로 실제 결제 증거가 아니다.

```powershell
$env:VITE_ENABLE_DEMO_AUTH='true'
pnpm.cmd exec vite build --outDir artifacts/chat-preview-dist
Remove-Item Env:VITE_ENABLE_DEMO_AUTH
pnpm.cmd exec vite preview --port 5192 --outDir artifacts/chat-preview-dist
```

별도 터미널에서:

```powershell
$env:PLAYWRIGHT_EXTERNAL_SERVER='1'
$env:PLAYWRIGHT_BASE_URL='http://127.0.0.1:5192'
pnpm.cmd exec playwright test tests/e2e/chat-intake.spec.ts tests/e2e/customer-flow.spec.ts --timeout=45000
```

검사 후 테스트 미리보기만 Ctrl+C로 종료한다. 실제 상담 미리보기 5194와 혼동하지 않는다.
