# 모바일 전환 검증 — 2026-09-05

## 변경

- 고객 주 제품을 iOS·Android 앱으로 변경. 웹은 보조 제품으로 유지.
- `mobile/`에 Expo57/React Native0.86 앱 추가. 웹뷰 방식이 아님.
- 이메일/비밀번호 로그인·가입, 갱신 토큰 SecureStore 보관.
- 기존 실제 상담 API 연결, 영어·스페인어, 카메라/사진첩/영상/음성파일, 동의와 파일 제한.
- 서명된 대화·질문 건너뛰기·잠정 범위 확인·첨부 업로드 재시도.
- 계정별 임시 상담과 원본 첨부를 앱 전용 저장소에 보존, 초기화/로그아웃 시 삭제.
- `pnpm dev`는 모바일과 API 실행. `pnpm dev:website`와 `dev:stable`은 보조 웹 실행.

## 확인한 증거

- 모바일 TypeScript 검사 통과.
- 파일 수·용량 제한, 0명 매칭, 서명 없는 응답 거절 테스트5/5 통과.
- Expo 의존성 검사: 호환 버전 일치.
- Metro Android 개발 번들: HTTP200,926모듈,6,558,112바이트.
- Metro iOS 개발 번들: HTTP200,925모듈,6,549,575바이트.
- 린트 오류0. Fast Refresh 상수 공동 내보내기와 외부 저장소 동기화 관련 경고3개는 남아 있다.

위 번들은 JavaScript 실행 코드 검사다. APK/IPA 생성 또는 실제 기기 실행 통과를 뜻하지 않는다.

## 실행이 막힌 부분

- 공식 Expo Go57.0.9를 안드로이드 에뮬레이터에 설치했다.
- API36 기본·2GB 및 API33 1.5GB에서 앱 실행 전 Android 시스템 응답 없음이 반복됐다. PC 여유 RAM은 약0.3~0.7GB였다.
- 반복을 중단하고 이 작업이 실행한 에뮬레이터만 종료했다. 기존 데이터는 보존했다.
- 실제 로그인·카메라 권한·영상 업로드·키보드·AI 응답은 모바일 기기에서 아직 확인하지 못했다.
- 아이폰 기기/시뮬레이터 실행, 서명된 IPA/APK, TestFlight/Play 배포도 수행하지 않았다.
- 근거: `artifacts/android-runtime-check.json`, `artifacts/wecover-android-current.png`.

## 다음 실행

메모리 여유가 있는 PC의 안드로이드 에뮬레이터 또는 실제 휴대폰에서 `mobile/README.md`대로 실행하고 로그인→촬영/사진 선택→AI 질문→스킵 경고→확정→업로드를 확인해야 한다. 앱은 현재 에뮬레이터 전용 로컬 주소로 설정되어 있으므로 실제 휴대폰에서는 접근 가능한 서버 주소로 바꿔야 한다.

Apple 서명과 EAS 계정 연결·스토어 게시·결제는 하지 않았다. 기존 명세의 전담 기사/묶음 작업/유지보수/전체 거래 화면 이식은 이 모바일 전환만으로 완료된 것이 아니다.
